## The slogan

> Your Solana wallet agent turns Solana's noise into one calm line: spend this, skip that.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22.18+) writes the slogan to `/output/entry.txt`. It creates
`/output` only if it is missing and overwrites the file in place — it never
deletes the directory, since the grader bind-mounts it. The output is fully
deterministic: the same line on every run. The program also guards the gate
itself (1–140 chars, at most 20 words) before writing.
